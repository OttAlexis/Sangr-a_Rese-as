# Proyecto:
Es un sistema de comentarios sin registro previo, con un sistema de calificación con estrellas.

# Flujo de trabajo:
1. Hacer una página base
2. Hacer una caja de comentarios, hacer que se publiquen dichos comentarios
3. Hacer una base de datos para almacenar y gestionar los comentarios
4. Hacer las conexiones; con la database, con los Scrips.
5. Publicar

## herramientas:
MySql, HTML, CSS, JS, Python
# Problemas:
1. No tener un sistema de registo puede llevar a que se publiquen reseñas con intenciones maliciosas como si nada.
